아티팩트가 뭔가요

방금 우리가 GEO 문서를 올린 그것입니다. 그림 셋으로 설명하겠습니다.

한 줄로

아티팩트는 대화에서 꺼내 놓은 웹페이지 한 장입니다. 주소가 있어서, 대화를 닫아도 남습니다.

어떤 형식인가요

HTML 파일 한 장입니다. 그 이상도 이하도 아닙니다. 글·표·그림·버튼·탭이 다 들어갈 수 있고, 올리면 진짜 웹페이지처럼 열립니다.

고치면 어떻게 되나요

같은 주소에 새 판이 쌓입니다. 새 링크가 생기지 않습니다.

이게 아티팩트의 핵심입니다. 이미 링크를 받아 간 사람은 아무것도 안 해도 새 판을 보게 됩니다. 오늘 우리가 그렇게 세 번 올렸습니다.

로컬 파일과 뭐가 다른가요

둘 다 필요합니다. 하나를 고르는 문제가 아닙니다.

내 맥의 HTML 파일아티팩트
어디 있나내 컴퓨터 안클로드 서버
폰에서 열기안 됨링크로 바로
남에게 보여주기파일을 보내야 함링크 하나
고쳤을 때내 파일만 바뀜같은 주소에 새 판
기본 공개 범위나만나만 비공개
없어질 위험내가 지우지 않으면 남음계정에 매여 있음
그래서 이 프로젝트는 둘 다 챙깁니다

아티팩트 링크만 드리지 않고 로컬 경로를 항상 같이 적는 이유입니다. 아티팩트는 읽는 자리, 로컬 파일은 정본입니다.

언제 쓰나요

쓰면 좋을 때
  • 남이 읽을 문서
  • 폰에서 볼 것
  • 여러 번 고칠 것
  • 표·그림이 많은 것
  • 링크로 건네야 할 것
안 쓰는 게 나을 때
  • 코드 파일
  • 한 줄이면 끝나는 답
  • 나만 볼 작업 메모
  • 밖으로 나가면 안 되는 내용

맨 아래 줄이 중요합니다

아티팩트는 기본이 비공개입니다. 내가 공유를 누르기 전에는 나만 봅니다. 다만 한 번 공유하면 링크를 아는 사람은 누구나 열 수 있고, 되돌리기가 번거롭습니다.

그래서 고객사 이름이 들어간 문서는

올리는 것 자체는 괜찮습니다 — 비공개니까요. 공유를 누르는 순간이 판단이 필요한 자리입니다.

오늘 우리가 한 것

말로만 설명하면 안 와닿으니, 실제로 벌어진 일을 그대로 적습니다.

순서무엇을 했나결과
1진단 문서를 .html로 씀내 맥에 파일 하나
2아티팩트로 올림주소가 생김 + 파비콘 🤖🔎
3틀린 것 셋을 고쳐 다시 올림같은 주소, 새 판
4실측 결과를 탭으로 붙여 또 올림같은 주소, 또 새 판

그래서 지금 그 링크를 폰에서 열면 제일 최신 판이 나옵니다. 링크를 다시 받을 필요가 없습니다.
