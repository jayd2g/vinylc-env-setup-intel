현대백화점 GA · 팀원 세팅 안내

Claude Code로 GA를 직접 읽게 만들기

개발 지식 없이 따라 할 수 있게 썼습니다. 대부분은 Claude에게 말로 시키면 됩니다 — 아래 파란 칸을 그대로 복사해 Claude Code에 붙여 넣으십시오. 사람이 직접 할 것은 4번의 브라우저 로그인 하나입니다.

1

무엇을 하려는 건가요

GA 화면에서 CSV를 내려받는 대신, Claude가 GA에 직접 물어보게 합니다.

지금까지는 사람이 GA 화면에서 CSV를 뽑아 Claude에 올렸습니다. 이제 Claude가 GA에 바로 질문합니다.

계정은 지금 쓰는 그 계정입니다

분석하는 사람 모두 담당자에게 받은 같은 고객사 계정을 씁니다. 새 계정을 만들지 않습니다. 다만 로그인은 각자 자기 컴퓨터에서 직접 합니다.

2

먼저 알아야 할 것 — 7일마다 다시 로그인

가장 많이 당황하는 지점이라 앞에 둡니다.

한 주가 지나면 연결이 스스로 끊깁니다

지금 방식에서는 로그인 효력이 7일입니다. 실제로 확인했습니다 — 9월 3일에 연결하고 9월 10일에 정확히 끊겼습니다.

고장이 아닙니다. Claude가 Token has been expired or revoked 같은 말을 하면 4번의 로그인 한 줄을 다시 돌리면 됩니다. 1분 걸립니다.

이 7일 제약을 없앨 수 있는지는 별도로 확인 중입니다. 없어지면 이 문단은 지워집니다 — 그때까지는 주 1회 재로그인을 전제로 쓰십시오.

3

준비 — Claude에게 시킵니다

깔 것이 셋인데, 직접 깔지 않습니다. 아래를 Claude Code에 붙여 넣으십시오.

CLAUDE CODE 에 붙여 넣기
GA 분석을 하려고 해. 맥이야. 아래 셋이 필요한데 없는 것만 깔아줘. ① google-cloud-sdk (gcloud 명령) ② uv ③ analytics-mcp (uv tool install analytics-mcp) 깔기 전에 무엇이 없는지 먼저 알려주고, 비밀번호를 물어보는 단계가 오면 내가 직접 칠 수 있게 멈춰서 알려줘.
Claude가 「Homebrew가 없다」고 하면

맥에 깔아 주는 손이 없다는 뜻입니다. 그것부터 있어야 나머지가 한 줄로 깔립니다. 환경세팅/맥/맥에서_두번누르기.command 를 두 번 누르십시오 — 무엇이 없는지 표로 알려 주고, 없는 것마다 무엇을 치면 되는지도 함께 줍니다. ⚠️ Homebrew 보다 Xcode 명령줄 도구가 먼저입니다(창이 떠서 [설치]를 눌러야 하고 몇 분 걸립니다).

비밀번호를 물어볼 수 있습니다

설치 중 컴퓨터 비밀번호를 묻는 창이 뜰 수 있습니다. 글자가 화면에 보이지 않아도 정상입니다 — 별표조차 안 나옵니다. 🚫 그 비밀번호를 Claude에게 알려 주지 마십시오. 직접 치는 것입니다.

4

로그인 — 브라우저 창만 본인이

이 절에 사람이 할 일이 하나 있습니다. 그것만 직접 하시면 됩니다.

담당자에게 받은 연결 파일(oauth-client-analytics-mcp.json)을 적당한 곳에 두고, 아래를 붙여 넣으십시오. 파일을 둔 곳만 바꿉니다.

CLAUDE CODE 에 붙여 넣기
GA 로그인을 해야 해. 연결 파일은 여기 있어 — <연결 파일을 둔 경로> 이걸로 gcloud application-default 로그인을 시작해줘. 범위는 analytics.readonly 와 cloud-platform 둘이야. 브라우저가 열리면 로그인은 내가 직접 할게.

브라우저가 저절로 열립니다. 거기서 로그인하면 끝입니다.

⭐ 반드시 「고객사 계정」으로 로그인하십시오

담당자에게 받은 계정(ehyundaidept@gmail.com)입니다. 자기 개인 계정이나 회사 계정으로 로그인하면 GA에 아무것도 보이지 않습니다. 브라우저에 다른 계정이 이미 로그인돼 있으면 계정을 바꿔 주십시오.

🚫 Claude에게 주지 말아야 할 것 · 남과 나누지 말아야 할 것

🚫 계정 비밀번호와 인증 코드를 Claude에게 알려 주지 마십시오. 로그인은 브라우저에서 본인이 하는 것이고, Claude는 그것 없이도 됩니다.

🚫 로그인하면 컴퓨터에 application_default_credentials.json 파일이 생깁니다. 이 파일은 계정 자격증명 그 자체입니다 — 다른 사람에게 주거나 받아서 쓰지 마십시오. 각자 자기 손으로 로그인하는 것이 규칙입니다.

5

Claude에 연결하고, 창을 다시 열기

설정 파일을 손으로 쓰지 않습니다. 이것도 Claude가 씁니다.

CLAUDE CODE 에 붙여 넣기
이 폴더에서 GA 를 쓸 수 있게 .mcp.json 을 만들어줘. - 서버 이름: google-analytics - 실행 파일: 내 홈의 .local/bin/analytics-mcp - GOOGLE_APPLICATION_CREDENTIALS: 내 홈의 .config/gcloud/application_default_credentials.json - GOOGLE_PROJECT_ID 와 GOOGLE_CLOUD_PROJECT: vinylc-ga-mcp 경로는 내 계정에 맞게 채워줘. 다 되면 무엇을 해야 하는지 알려줘.
⭐ 이렇게 시키면 함정 하나가 사라집니다

이 설정에는 경로에 계정명이 들어갑니다. 남의 것을 복사하면 남의 계정명이 그대로 들어와 연결이 안 됩니다. Claude가 쓰면 본인 계정으로 맞게 채워지니 그 실수가 아예 나지 않습니다.

Claude Code를 닫고 다시 열어야 붙습니다

연결은 창이 열릴 때 한 번만 확인합니다. 켜 둔 채로는 아무리 기다려도 안 보입니다.

됐는지 확인하는 법

다시 열고 Claude에게 「GA 계정 목록 보여줘」라고 해 보십시오. 속성 목록이 나오면 성공입니다.

6

막히면 — 함정 셋과 볼 곳

실제로 걸렸던 것들입니다.

함정 ① 「거부」를 누르면 영구히 막힙니다

처음 열 때 연결을 허용할지 묻는 창이 뜹니다. 여기서 거부를 누르면 그 선택이 저장되어 이후 모든 창에서 연결이 막힙니다. 더 나쁜 것은 목록에서 아예 사라져 「설치가 안 됐나」로 착각하게 된다는 점입니다.

터미널에 이 명령을 넣어 확인합니다 — Rejected 라고 나오면 그 경우입니다.

claude mcp get google-analytics
함정 ② 남의 설정 파일을 복사하지 마십시오

.mcp.json 의 경로에는 계정명이 들어갑니다. 남의 것을 그대로 복사하면 연결이 안 됩니다. 5번처럼 Claude에게 만들어 달라고 하면 이 문제가 생기지 않습니다.

함정 ③ 여러 사람이 자주 다시 로그인하면 서로를 밀어냅니다

한 계정에 살아 있을 수 있는 로그인 수에 한도가 있어(약 50개), 넘으면 오래된 것이 조용히 무효화됩니다. 인원이 늘면 재로그인 주기를 관리자와 맞추십시오.

분석 대상 속성은 「홈페이지 - GA4」 하나입니다.
