03 — PATHS

③ IDE에서 쓰기 — 사실은 두 가지입니다

이름이 비슷해 섞이기 쉽지만, 서로 다른 이야기입니다.

③-가
Claude Code를 IDE에 붙이기
VS Code · JetBrains 공식 확장
터미널·데스크탑 앱과 똑같은 Claude Code가 그대로 도는 것입니다. 같은 계정, 같은 사용량을 씁니다. 사용량 확인도 됩니다.
③-나
다른 IDE에 API 키를 꽂아 ‘모델만’ 쓰기
Cursor 등
말 그대로 모델만 땡겨오는 것이라, 사용량 리셋이나 현재 사용량 확인 같은 모델 이용에 딸린 기능이 없습니다. 요금도 따로 셉니다.
이런 이용 방법 중에, 우리는 ②를 택하려고 합니다.
여러 에이전트를 동시에 쓸 땐 IDE가 좋지만, 우리가 쓰기엔 쓸데없이 복잡하다는 인상이 살짝 있습니다.

04 — CHAT & CODE

왜 code와 일하는가

개발사가 구성한 것과는 조금 다르게, 이렇게 이해하시면 좋습니다.

Claude
모델 이름
데스크탑 앱의 chat
Claude 모델을 이용한 ‘대화’ 중심 화면
데스크탑 앱의 code
Claude 모델을 이용한 ‘실행’ 중심 화면

엄밀하게는, 당연히 Claude Code는 코딩을 하기 좋게 만들어진 도구입니다. 그런데 —

우리가 만드는 모든 파일은 사실 코드로 되어 있습니다.

그리고 얘는 권한이 다양합니다. 파일을 읽고, 쓰고, 정리하고, 지우는 걸 다 할 수 있습니다. 그래서 얘하고 같이 일을 하는 게 편안합니다.

05 — SETUP

파이썬 · brew

01
파이썬
프로그래밍 언어입니다. 이걸 깔아 두면, Claude Code가 필요할 때 자기가 필요한 프로그램을 짜서 그걸 돌립니다.
예를 들어 “화면 A와 B를 비교해줘” 하면, Claude Code는 파이썬으로 비교하는 프로그램을 짜고 그걸 돌릴 수 있습니다.
맥에는 파이썬이 이미 들어 있는 경우가 많습니다. 점검기가 재 보고 없을 때만 깔자고 합니다.
02
brew
앱스토어 같은 겁니다. 근데 사람이 눈으로 보고 고르는 게 아니고, 터미널에서 필요한 걸 쉽게 설치하게 도와주는 겁니다.
맥 전용입니다. 윈도우에는 brew가 없고, 같은 자리에 해당하는 다른 것을 씁니다. 윈도우용 점검기가 무엇을 어떻게 깔지 알려 줍니다.
인텔 맥이면 brew를 아예 건너뜁니다. 2026년 9월부터 Homebrew가 인텔 맥 지원을 3등급으로 내려, 설치가 몇 시간 걸리거나 실패합니다. 점검기가 알아서 직접 받는 길로 안내하니 신경 쓰지 않으셔도 됩니다.

05 — SETUP

node.js · git

03
node.js
자바스크립트 기반의 일종의 ‘환경’입니다. 이걸 깔아 두면 node.js를 가지고도 필요한 프로그램을 짜고 돌려 줍니다.
사실 진짜 이유는 따로 있습니다 — 뒤에 나올 연결(MCP)의 상당수가 node.js 위에서 돕니다. 그래서 연결을 붙이시려면 node.js가 먼저 있어야 합니다. 다만 웹 주소로 붙는 연결은 node.js 없이도 됩니다.
04
git — 되돌리기 기록장
고친 것을 한 판씩 저장해 둬서, 잘못돼도 그 지점으로 돌아갈 수 있습니다. 저장 버튼은 사람이 눌러야 하는데 — 그걸 Claude가 대신 눌러 줍니다.
Claude에 연동해 두면 내가 만든 걸 등록하고, 쉽게 공유하거나 배포할 수 있습니다.

개념 ④ 환경 관리 — MCP

MCP는 일종의 연결 도구입니다. 콘센트에 가깝습니다.

피그마는 미리 알아 두실 것 — 호출 한도가 월 단위로 꽤 빡빡합니다. 다 쓰면 그리기는 물론 읽기까지 막히고, 월 단위라 기다린다고 풀리지 않습니다.

06 — MANAGE

스킬과 에이전트

스킬은 매뉴얼, 에이전트는 그 매뉴얼을 들고 일하는 조수입니다.

SKILL
스킬 — 매뉴얼
Claude는 뭐든 잘하지만, 더 잘하게 하는 방법이 스킬입니다. 사람들이 만들어 둔 스킬을 활용하면 좋습니다.

설치하고 해당 스킬을 써 달라고 얘기하면, ‘매뉴얼을 읽고 거기 써 있는 대로 일해라’고 지시하는 것입니다.
AGENT
에이전트 — 역할이 정해진 조수
매뉴얼을 들고 자기가 직접 일을 수행하는 아이입니다.

· 여러 에이전트를 동시에 묶어서 돌릴 수 있습니다
· 에이전트마다 권한이나 도구를 다르게 줄 수 있습니다
자동 실행은 에이전트가 아니라 ‘훅(hook)’이 맡습니다 — 에이전트가 스스로 조건을 보고 뜨지는 않습니다. “이 일이 끝나면 저걸 해라”를 미리 걸어 두는 별도 장치가 훅입니다.

세 단계

01
「환경세팅」 폴더를 통째로 두세요
안의 파일을 따로 꺼내면 서로를 찾지 못합니다. 두는 자리는 상관없습니다 — 바탕화면이든 다운로드든.
02
Claude 앱을 열고, 이 폴더를 고르세요
왼쪽에서 Code · 실행 위치는 Local · 폴더는 「환경세팅」 폴더 전체. Cloud를 고르면 내 컴퓨터를 못 재서 의미가 없습니다. 「이 폴더를 믿어도 되나」를 물으면 허용하셔야 진행됩니다.
03
입력창에 /환경세팅-도우미 를 치세요
재는 것부터 깔기까지 도우미가 이끕니다. 무엇을 붙일지 먼저 고르게 하고, 깔 때마다 묻습니다. 비밀번호가 필요한 설치와 창을 띄우는 로그인은 사람에게 넘깁니다.
두 번째 길 — 회사 방침상 명령 실행을 맡길 수 없거나 Code가 안 열리면 맥/맥에서_두번누르기.command(윈도우는 윈도우\윈도우에서_두번누르기.bat)를 두 번 누르십시오. 재기만 합니다 — 아무것도 설치하지 않고, 설치 명령이 적힌 안내서만 나옵니다.
